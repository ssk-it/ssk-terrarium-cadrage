# Identité visuelle

Le logo de ssk-terrarium : les accolades forment les parois du bac, avec son couvercle, et l'escargot vit dedans. Les fichiers viennent tels quels du jeu de logos du projet ; ils ne se recolorent ni ne se recomposent.

- `symbole.svg` — l'icône principale, sur son propre fond `#8ecae6` : elle convient aux deux fonds.
- `logotype-clair.svg` — le logotype horizontal, pour un fond clair.
- `logotype-sombre.svg` — le logotype horizontal, pour un fond sombre (`#023047`).
